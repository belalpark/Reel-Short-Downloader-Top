## ما بقي معلقًا

- **المسار الإيجابي على Microsoft Edge الحقيقي:** تحميل الإضافة يدويًا وربطها ثم نجاح زر الإتمام وظهور Finish. اختبارات Chromium والوحدات لا تحل محل هذه الخطوة.
- **حساب ReelShort الفعلي وفهرس المستخدم:** لا يحتوي المرفق على حساب أو CSV فعلي. أعداد 45/8 بيانات اختبار اصطناعية. لم يُثبت تنزيل حلقات المستخدم أو تطابق محتواها.
- اختبار Windows 10/11 على جهاز فعلي، وDPI ‏125/150%، والترقية بين إصدارين، وإيقاف تنزيل طويل واستئنافه، والاحتفاظ ببيانات المستخدم بعد الإزالة.
- لا توجد شهادة توقيع؛ الحزمة التجريبية غير موقعة، ولا تُعامل كإصدار إنتاجي معتمد.
- يجب تحديث vendor-lock.json بمراجعة صريحة إذا حُذفت إصدارات الأدوات المنبع أو احتاجت تحديثًا؛ لا يوجد تنزيل بديل يتجاوز فحص SHA256.

راجع [قائمة القبول الكاملة](ACCEPTANCE.md). يُنفذ تفعيل الإضافة وفق خطوات Edge المدعومة؛ لا تعديل صامت لسياسات المتصفح. التعرف على Edge يعتمد على User-Agent في طلب الإضافة المقترنة، وهو دليل تشغيل وليس إثباتًا تشفيريًا لهوية المتصفح. تنتهي حالة الاتصال بعد 75 ثانية دون heartbeat.

## عوائق ظهرت وعولجت

- صورة ubuntu-latest انتقلت إلى إصدار لا يدعمه Playwright المثبت؛ ثُبتت البيئة على Ubuntu 24.04 ونجح الاختبار.
- غابت ملفات ترخيص Tcl/Tk المنفصلة من Python على Windows؛ حُفظت النصوص الرسمية بمصادرها وبصماتها داخل third_party، ثم نجح البناء.
- فشل مسار الإلغاء بعد نسخ الملفات بسبب سلوك Inno Setup الافتراضي؛ استُخدمت صفحة تحقق مستقلة وخروج غير مكتمل مع تنظيف عادي. أثبت الاختبار رمز الخروج 12 ونجاح الإزالة.
- غطى شريط المهام أسفل النافذة في صورة مبكرة؛ عُدلت الأبعاد إلى مساحة العمل الفعلية وأعيد فحص الأزرار والصور.
- صححت أداة اختبار أزرار Windows وقراءة النوافذ، وقيس heartbeat عند الخادم المحلي مباشرة بدل الاعتماد على أحداث شبكة Playwright للـservice worker.

لم يُنشر إصدار إنتاجي، ولم يُعلن اكتمال أي بند قبول حقيقي لم يُختبر.
