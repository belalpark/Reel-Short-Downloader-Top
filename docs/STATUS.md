# سجل التنفيذ والتحقق

آخر تحديث: 14 نوفمبر 2026، الرياض.

## ما تم التحقق منه محليًا

- المستودع `belalpark/Reel-Short-Downloader-Top` متاح للقراءة والكتابة؛ كان يحتوي README فقط، ورأس main وقت الفحص `be70fcef4dae343bc7edf159ec824263f3b1ddba`.
- ZIP المرفق: CRC سليم لجميع العناصر؛ 15 ملفًا. حُفظ الأصل داخل `legacy/v5.3`.
- **25 اختبار Python ناجحًا**: فهرس 45/8، رفض الملفات غير المتسقة، ارتباط الحلقات، سلامة الملفات، الربط المحلي، الأصل/Host، المهلة، محاولات الرمز، ورفض Chrome كـ Edge.
- **10 اختبارات JavaScript ناجحة**: استيراد 45/8، HLS بمعلمات استعلام، صيغ CSV، توقيت التشغيل، تبديل عنصر الفيديو، والتوقف أثناء الانتظار مع حفظ حالة STOP.

## المنفذ ويحتاج تحقق Windows/CI

- تطبيق 0.1.0 بواجهة عربية، قائمة حلقات، اختيار ملف ومجلد صريحين، قائمة تنزيل، إيقاف/استئناف، فحص FFprobe وسجل منقح.
- إضافة 5.3.1 مع الإصلاحات والربط المحلي؛ قناة الربط لا تنقل أوامر تنزيل أو فهارس أو ملفات حساب.
- تثبيت داخل حساب المستخدم دون صلاحيات مدير، مع أدوات مضمنة وفحص سلامة وتشغيل قبل الإتمام.
- بوابة تفعيل فعلية تتطلب إصدار الإضافة الصحيح وheartbeat حديثًا من Edge. تعريف Edge يعتمد على User-Agent من طلب الإضافة المقترنة؛ هذه قرينة تشغيل وليست إثباتًا تشفيريًا لهوية المتصفح.
- GitHub Actions لاختبارات Linux/Windows، اختبار متصفح بصفحة وفيديو اصطناعيين، بناء EXE، فحص runtime وGUI، اختبار رفض المثبّت دون تفعيل، ثم حزم وchecksums. وسوم v* تنشئ مسودة إصدار تجريبي فقط.

## العوائق والحدود الحالية

- لا توجد بيئة Windows أو Inno Setup أو PowerShell في بيئة التنفيذ المحلية. لا يمكن اعتماد EXE من Linux؛ يجب متابعة نتيجة بناء Windows في GitHub Actions.
- محاولة إطلاق Chromium المحلي فشلت بسبب منع socket من بيئة التنفيذ؛ لم يُسجل نجاح لاختبار المتصفح المحلي. أُضيف الاختبار إلى CI.
- لا يوجد حساب ReelShort حقيقي أو CSV فعلي في المرفق. اختبار 45/8 يستخدم بيانات اصطناعية مماثلة، وليس إثباتًا لنجاح التنزيل من حساب المستخدم.
- تفعيل Edge يتم يدويًا وفق مسار Microsoft المدعوم. لا يمكن الادعاء بتثبيت/تفعيل صامت مضمون على أجهزة المستهلكين.
- اختبار رفض المثبّت آليًا لا يثبت مسار النجاح التفاعلي؛ هذا المسار وقبول الواجهة وDPI والإيقاف/الاستئناف الحي في [قائمة القبول](ACCEPTANCE.md).
- لا توجد شهادة توقيع. لا تُصنّف الحزم التطويرية كإصدار إنتاجي موثوق التوقيع.
- بقاء ملفات عند إلغاء الإعداد مقصود لإتاحة إعادة التحقق أو إزالة التطبيق. التنزيلات وبيانات المستخدم منفصلة ولا تُحذف ضمن الإزالة.

كل مرحلة غير مثبتة بنتيجة اختبار موثقة تبقى معلقة. تُضاف نتائج GitHub Actions الفعلية إلى هذا الملف بعد متابعتها.
