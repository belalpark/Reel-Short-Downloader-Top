# قبول الإصدار 0.2.0 على Windows

تقتصر ادعاءات التحقق على الأدلة المرفقة بالتشغيل المشار إليه في [STATUS](STATUS.md). لا يثبت الاختبار الاصطناعي صلاحية حساب المستخدم أو مطابقة فيديوهات ReelShort الفعلية.

| السيناريو | النتيجة المطلوبة | وسيلة الإثبات |
| --- | --- | --- |
| الواجهة | ثلاثة أزرار ظاهرة ١، ٢، ٣ دون رمز ربط أو اختيار CSV | صورة EXE وفحص الواجهة في CI |
| متطلبات سليمة | Finish ثم فتح التطبيق العادي | اختبار المثبّت التفاعلي الحقيقي |
| تثبيت صامت | نجاح عند سلامة المتطلبات الأساسية دون مطالبة بالتفعيل | Test-Installer.ps1 |
| أداة مفقودة/متغيرة | فشل سلامة الحزمة ورمز 12، وعدم تنفيذ أداة غير موثوقة | اختبار الحزمة المثبتة |
| غياب Edge | متطلب غير جاهز ورسالة قابلة للتنفيذ؛ لا Finish ناجح | قبول على جهاز نظيف |
| إضافة الملحق | زر ٢ ينفذ واجهة Edge العادية ويثبت v5.4.0 دون رمز | Edge حقيقي بملف اختبار مستقل واتصال موثّق |
| Edge يعمل مسبقًا | تحميل الملحق في الملف نفسه، دون ضياع جلسة الموقع | اختبار Edge الجاري وقبول حساب المستخدم |
| سياسة جهاز تمنع Developer mode | إظهار السبب ومسار المجلد والخطوة اليدوية المحددة | قبول على جهاز مُدار |
| بدء من التطبيق | فهرس في Inbox ثم تنزيل روابط جديدة تلقائيًا دون ملف يختاره المستخدم | المتصفح والـreceiver والـwatcher الفعليان، مع مراقب لطابور التنزيل |
| ظهور رابط لاحقًا | إعادة زيارة الحلقة الناقصة وحدها ثم إدراجها مرة واحدة | صفحات اختبار ذات رابط يظهر في الجولة الثانية |
| مصدر لا يظهر | انتهاء بعد ثلاث جولات وعرض العدد الناقص | اختبار المتصفح |
| إيقاف أثناء تأخير التحديث | عدم تنفيذ التحديث المجدول | اختبار المتصفح |
| إعادة فتح التطبيق فور إغلاقه | تحرير المنفذ، ورفض مستمع ثانٍ أثناء تشغيله | اختبار اتصال مصادق عليه ثم إغلاق وربط المنفذ نفسه على Windows وLinux |
| إعادة تشغيل التطبيق أثناء الفحص | وقف الجلسة القديمة وإلغاء تحديثها، ثم بدء جلسة جديدة دون ضبط يدوي | إعادة تشغيل receiver الفعلي أثناء تأخير التحديث داخل اختبار المتصفح |
| رابط محفوظ من جلسة سابقة | لا يبدأ تنزيل رابط مؤقت قديم؛ يُعاد جمع المصدر | حالة متصفح مسبقة برابط قديم مع مراقب لطابور التنزيل |
| إغلاق الصفحة أو غياب رد الملحق | لا بدء باستخدام صفحة قديمة، ولا تعليق الأزرار إلى أجل غير محدد | اختبارات صلاحية الصفحة وانتهاء الأمر |
| تقييد الموقع 429/503 | توقف الفحص وطلب المحاولة لاحقًا | منطق توقف واختبار حساب/شبكة عند توفر الحالة |
| HLS غير المؤكد | لا يُرقّى إلى مصدر تنزيل | اختبارات المصدر والفهرس |

| تكرار التشغيل | عدم تنزيل ملف سبق فحصه داخل مجلد الحفظ الحالي | سجل المكتملات وفحص إعادة التنزيل |
| إيقاف تنزيل طويل واستئناف | وقف العملية وبقاء .part ثم استئنافه | فيديو كبير مرخص على جهاز Windows فعلي |
| تغيير مسار الحفظ | استخدام المسار الجديد وحفظه للتشغيل التالي | قبول جهاز المستخدم |
| الإزالة | إزالة التطبيق والاحتفاظ ببيانات المستخدم والفيديوهات | إزالة فعلية في CI؛ تحقق المستخدم من بياناته |
| Windows 10/11 وDPI 125/150% | نصوص عربية وأزرار دون قطع | صور قبول يدوي لكل وضع |
| حساب ReelShort الحقيقي | صلاحية الوصول، ظهور الروابط، تطابق عدة حلقات محفوظة | لم يُختبر دون حساب/مدخلات المستخدم |
| الترقية من 0.1.0 | نفس مجلد البيانات مع إضافة جديدة لا تتطلب PIN | قبول تثبيت الإصدارين على الجهاز نفسه |

تُترك كلمة مرور الحساب داخل Edge. لا تُنشر بيانات الاتصال الخاصة أو روابط الفيديو الموقّعة أو كوكيز المستخدم في تقارير المستودع.
