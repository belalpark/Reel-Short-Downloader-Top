# قبول التطبيق والمثبّت على Windows

لا تُعلن جاهزية الإنتاج إلا بعد توثيق كل بنود هذه الصفحة على جهاز Windows 10/11 x64 نظيف. اختبار Chromium الاصطناعي لا يحل محل اختبار Microsoft Edge وحساب المستخدم الحقيقي.

| السيناريو | النتيجة المطلوبة | وسيلة الإثبات |
| --- | --- | --- |
| بناء التطبيق والمثبّت | إنشاء EXE ونسخة محمولة مع SHA256 | سجل GitHub Actions والحزم |
| تشغيل دون Python أو أدوات على PATH | نافذة التطبيق تعمل وتستخدم أدوات الحزمة | سجل runtime وصورة GUI |
| Edge غير موجود | متطلب Edge غير جاهز؛ الإتمام غير متاح | لقطة شاشة |
| أداة ناقصة أو معدلة | فشل سلامة الحزمة؛ لا تنفيذ للأداة ولا Finish | اختبار ملف معدل ولقطة |
| نسخة ثانية/منفذ 18765 مشغول | رسالة عائق اتصال واضحة؛ لا إتمام | تشغيل نسختين |
| رمز خاطئ/منتهي | رفض الربط؛ بعد خمس محاولات يلزم رمز جديد | اختبارات وحدة وقبول حي |
| تشغيل الإضافة داخل Chrome | لا يُقبل كاتصال Edge | اختبار Chromium وقبول حي |
| تحميل الإضافة من المجلد الثابت داخل التثبيت | ظهور v5.3.1 وربط ناجح داخل Edge | صورة Edge ونافذة التطبيق |
| إغلاق Edge أو تعطيل الإضافة | سقوط حالة الاتصال خلال 75 ثانية دون heartbeat | توقيت وصورة |
| إغلاق نافذة الإعداد قبل اكتماله | خطأ تثبيت وخروج غير صفري؛ لا نجاح مزعوم | سجل المثبّت |
| تثبيت صامت جديد | رفض بسبب عدم إثبات التفعيل | Test-Installer.ps1 في CI |
| تفعيل حي + متطلبات سليمة | إتمام الإعداد ثم ظهور Finish | **اختبار يدوي لم يُثبت بعد** |
| العربية/الشاشات 1366×768 و1920×1080 وDPI 125/150% | أزرار ونصوص قابلة للاستخدام بلا قطع | صور لكل وضع |
| CSV الفعلي 45 حلقة و8 MediaURL | 45 صفًا و8 حلقات قابلة للاختيار | CSV من المستخدم، دون نشر الروابط |

| رابط ساري مرخص | تنزيل وفحص FFprobe وفتح الملف | ملف اختبار مرخص وتقرير |
| رابط منتهي/403/مصدر DRM | فشل واضح دون ادعاء اكتمال أو تجاوز | تقرير فشل منقح |
| تطابق الفيديو والحلقة | فحص بشري لعدة حلقات بمصادر مختلفة | قائمة عينات وتوقيتات |
| إيقاف/استئناف تنزيل جزئي | وقف شجرة العمليات وبقاء .part ثم استئناف | عينة فيديو كبيرة مرخصة |
| فشل FFprobe/ملف فارغ/صوت فقط | لا يُسجل الفيديو كمكتمل | اختبارات وحدة وقبول تنزيل |
| إزالة البرنامج | إزالة ملفات التطبيق مع الاحتفاظ ببيانات المستخدم والتنزيلات | اختبار المثبّت ثم فحص المجلدات |
| ترقية بنفس المسار | الحفاظ على الفهرس وعدم إعادة إنشاء هوية الإضافة | تثبيت إصدارين متتاليين |

الاختبارات المطلوبة على حساب ReelShort تقتصر على الوصول العادي للمحتوى المتاح للمستخدم. لا تُجمع بيانات حساب أو كوكيز أو مفاتيح DRM في تقارير المشروع.
