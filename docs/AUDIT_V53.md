# مراجعة المصدر المرفق v5.3

تاريخ المراجعة: 14 نوفمبر 2026. المصدر: `Drama_Series_Scanner_v5_3.zip` المرفق في هذه المحادثة. فحص CRC لجميع عناصر ZIP نجح؛ يحتوي 15 ملفًا، ولا يحتوي تطبيق Windows أو مثبّتًا أو اختبارات أو GitHub Actions. المستودع وقت الفحص احتوى README فقط.

حُفظت جميع ملفات المصدر الأصلي دون تغيير في `legacy/v5.3`. لا يضم المثبّت السكربتات القديمة أو يشغّلها.

## تحديث 0.2.0 / الإضافة 5.4.0

أزيل رمز الربط واختيار CSV من مسار الاستخدام الأساسي. ينقل الملحق الفهرس إلى Inbox خاص بالمستخدم، ويقرأ التطبيق تحديثاته تلقائيًا بمعرف مستقل لكل تحديث. إعادة فحص الناقص محدودة بثلاث جولات وتأخير متزايد، مع إيقاف قابل للتحقق. الجلسة الجديدة تحدّث الروابط المؤقتة، وإعادة تشغيل التطبيق تُلغي الفحص القديم. بقيت الملفات الأصلية v5.3 دون تعديل، وبقيت اختبارات ترحيل 45 حلقة و8 روابط ومرشحات HLS ضمن اختبارات التراجع. نتائج التنفيذ الفعلية وحدودها في [STATUS](STATUS.md).
