# Reel Short Downloader Top

[![Windows checks](https://github.com/belalpark/Reel-Short-Downloader-Top/actions/workflows/windows.yml/badge.svg)](https://github.com/belalpark/Reel-Short-Downloader-Top/actions/workflows/windows.yml)

تطبيق Windows بواجهة واحدة وثلاثة أزرار. الإصدار **0.2.1** مع الإضافة **5.4.1** يزيل رمز الربط واختيار CSV يدويًا. نتائج الاختبار وحدوده موثقة في [سجل التحقق](docs/STATUS.md).

## الاستخدام

ثبّت البرنامج على Windows 10/11 x64 مع Microsoft Edge. أدوات التنزيل مضمّنة؛ لا أوامر PowerShell ولا تثبيت Python يدويًا.

1. **افتح موقع المسلسل:** سجّل دخولك بالطريقة العادية داخل Edge، وافتح المسلسل المطلوب أو إحدى حلقاته.
2. **أضف الملحق:** يفتح البرنامج صفحة إضافات Edge وينفذ Developer mode ثم Load unpacked من الواجهة العادية، ويربط الملحق تلقائيًا. لا كلمة مرور أو رمز ربط. تصبح الحالة «الملحق جاهز ومتصل تلقائيًا» بعد اتصال فعلي. يكفي تنفيذها مرة واحدة، وتُعاد بعد ترقية البرنامج لتحديث الملحق.
3. **ابدأ التنزيل:** يفهرس الملحق الحلقات في الخلفية ويرسل الروابط المتاحة إلى مسار معروف للتطبيق. يبدأ التنزيل مباشرة، ويحفظ الفيديو في **Downloads / Reel Short Downloader Top**. يمكن فتح مجلد الحفظ أو تغييره من النافذة نفسها.

لا تحتاج فتح نافذة الملحق أو تصدير CSV. يُحفظ الفهرس الداخلي تلقائيًا في `%LOCALAPPDATA%\ReelShortDownloaderTop\Inbox`، ويقرأه التطبيق أثناء وصول حلقات جديدة. لا يعيد تنزيل الملفات التي سبق نجاح فحصها داخل مجلد الحفظ الحالي. بدء محاولة جديدة يجمع روابط جديدة بدل إعادة استخدام الروابط المؤقتة القديمة. عند إعادة فتح التطبيق يتوقف الفحص القديم تلقائيًا، ويمكن البدء مجددًا دون إعادة ضبط الملحق.

تُعاد زيارة **الحلقات الناقصة فقط** مع تحديث الصفحة، بحد أقصى ثلاث جولات وتأخير متزايد. زر **إيقاف** يلغي التنزيل والتحديثات التالية. إذا لم يظهر رابط بعد المحاولات، يعرض التطبيق النقص بوضوح ويمكن إعادة المحاولة لاحقًا. تحديث الصفحة لا يفتح حلقة مقفلة ولا يضمن ظهور رابطها؛ الوصول يعتمد على حسابك والموقع. يتوقف الفحص عند رفض الموقع أو تقييد الطلبات بدل تكرارها بلا نهاية.

إذا منع Edge إضافة الملحق بسبب سياسة الجهاز أو تغيرت واجهته، يظهر السبب مع زر يفتح صفحة الملحقات وآخر ينسخ المجلد الجاهز؛ أكمل تحميله مرة واحدة بالطريقة [الموثقة من Microsoft](https://learn.microsoft.com/microsoft-edge/extensions-chromium/getting-started/extension-sideloading). لا يغيّر البرنامج سياسات الجهاز.

## تحديث مشكلة التوقف عند الحلقة ٩

إذا كانت الحلقة المدفوعة تعمل داخل Edge وبقيت في التطبيق «لم يظهر بعد»، حدّث إلى 0.2.1، ثم اضغط ٢ لتحديث الملحق، وبعد ظهور الاتصال اضغط ٣. احتفظ بمجلد الحفظ نفسه حتى يتجاوز التطبيق الملفات التي سبق فحصها. كان الإصدار 0.2.0 يجمع مصادر HTML، ويحتفظ بروابط HLS كمرشحات فقط، ولذلك لم ينزّل الفيديو الذي يعمل عبر blob دون رابط صريح في الصفحة. الإصدار الجديد يطابق بث HLS المرصود مع مدة الفيديو ومقاطع حمّلها مشغّل الحلقة قبل إرساله للتنزيل.

## التثبيت والتحقق

المثبّت يفحص Windows وEdge وسلامة ملفات الحزمة وتشغيل yt-dlp وFFmpeg وFFprobe وصلاحيات مجلدات البيانات والحفظ قبل Finish. تفعيل الملحق يتم من الزر ٢ داخل التطبيق، ولا توجد نافذة ربط أخرى أثناء التثبيت. التثبيت الصامت ينجح عند سلامة المتطلبات الأساسية؛ لا يعني ذلك أن الملحق مُفعّل. فشل المتطلبات يُرجع الرمز 12.

للمثبّت وحده، افتح أحدث تشغيل ناجح في [تنزيل المثبّت](https://github.com/belalpark/Reel-Short-Downloader-Top/actions/workflows/installer-download.yml) ونزّل `ReelShortDownloaderTop-Installer-only`. تُراجع بصمات البناء الأصلي قبل فصل المثبّت. تتوفر الحزمة الكاملة والنسخة المحمولة في [بناء Windows](https://github.com/belalpark/Reel-Short-Downloader-Top/actions/workflows/windows.yml). لا تُعامل الحزمة التطويرية غير الموقّعة كنسخة إنتاجية معتمدة.

## البيانات وحدود التحقق

- بيانات التطبيق والملحق المنسوخ في `%LOCALAPPDATA%\ReelShortDownloaderTop`. يبقى المجلد ثابتًا بعد ترقية التطبيق.
- الربط المحلي على `127.0.0.1:18765` يستخدم token عشوائيًا خاصًا بالمستخدم، وهوية الملحق وإصداره. لا رمز يدوي ولا وصول لكلمات مرور Edge أو كوكيزه. ملف الإعداد الخاص غير متاح لصفحات الويب عبر manifest.
- يُنزّل التطبيق روابط MediaURL الصريحة المتاحة، وبث HLS بعد مطابقة مدته ومقاطع الفيديو التي حمّلها المشغّل مع الحلقة الحالية. لا يعتمد مرشحات HLS غير المؤكدة مصادر تنزيل. قد تنتهي صلاحية الروابط؛ أعد الفحص عند الحاجة.
- لا يسجّل النجاح إلا بعد نجاح أداة التنزيل وفحص مسار الفيديو بواسطة FFprobe. مطابقة المحتوى للحلقة على الحساب الفعلي تتطلب مراجعة حقيقية.
- لا يستخرج مفاتيح DRM ولا يتجاوز حقوق الوصول. استخدمه للمحتوى الذي يحق لك حفظه.
- الاختبارات الاصطناعية لا تثبت تنزيل حلقات حساب المستخدم؛ راجع [قائمة القبول](docs/ACCEPTANCE.md).

## البناء

على Windows x64 مع Python 3.12 وNode 22 و[Inno Setup 6](https://jrsoftware.org/isinfo.php):

```powershell
python -m pip install -r build-requirements.txt
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/extension.test.cjs
.\scripts\Download-Dependencies.ps1
python scripts/package.py
& 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' installer\ReelShortDownloaderTop.iss
```

تُثبت أدوات التنزيل ببصمات SHA256 في `vendor-lock.json`. الاختبار المتكامل للمتصفح يعمل على صفحات وفيديو اصطناعيين:

```sh
npm install --no-save --package-lock=false playwright@1.56.1 hls.js@1.6.13
npx playwright install chromium
node tests/browser.cjs
# اختبار HLS يحتاج Chrome for Testing بترميز H.264/AAC؛ يهيئه CI تلقائيًا.
# HLS_BROWSER_EXECUTABLE=/path/to/chrome node tests/hls_browser.cjs
```

تعمل اختبارات Linux وWindows والمتصفح ثم بناء EXE والمثبّت تلقائيًا عند الدفع إلى main. يختبر CI التثبيت الصامت والتفاعلي والإزالة وإضافة الملحق عبر واجهة Edge الحقيقية داخل ملف مستخدم اختبار مستقل. عند دفع وسم `v*` يُنشأ إصدار تجريبي كمسودة فقط بعد نجاح الاختبارات.

المجلد `legacy/v5.3` يحفظ الملفات الأصلية دون تعديل. راجع [مراجعة المصدر](docs/AUDIT_V53.md) و[إشعارات المكونات الخارجية](THIRD_PARTY_NOTICES.md).
