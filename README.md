# Reel Short Downloader Top

[![Windows checks](https://github.com/belalpark/Reel-Short-Downloader-Top/actions/workflows/windows.yml/badge.svg)](https://github.com/belalpark/Reel-Short-Downloader-Top/actions/workflows/windows.yml)

تطبيق Windows لفهرسة حلقات ReelShort باستخدام إضافة Microsoft Edge، واستيراد CSV وتنزيل روابط الفيديو الصريحة، مع فحص الملفات الناتجة. **الإصدار 0.1.0 تطويري**؛ نجاح البناء الآلي لا يُعد اعتمادًا للتثبيت التفاعلي أو للاستخدام على حساب ReelShort حقيقي.

## حالة المشروع

راجع [سجل التحقق والعوائق](docs/STATUS.md) و[مراجعة v5.3](docs/AUDIT_V53.md). النسخة المرفقة الأصلية محفوظة دون تعديل في `legacy/v5.3`، والإضافة المعالجة في `extension` برقم **5.3.1**.

## التثبيت والاستخدام

1. من [GitHub Actions](https://github.com/belalpark/Reel-Short-Downloader-Top/actions/workflows/windows.yml)، افتح أحدث تشغيل **ناجح**، ثم نزّل ملف `ReelShortDownloaderTop-Windows-x64` من Artifacts. يتضمن المثبّت EXE ونسخة محمولة وملف SHA256SUMS.
2. شغّل المثبّت على **Windows 10/11 x64** مع Microsoft Edge مثبت. تتضمن الحزمة Python وyt-dlp وFFmpeg؛ لا تحتاج تثبيتها يدويًا أو تغيير PATH.
3. ستفتح نافذة إعداد التطبيق قبل إتمام التثبيت. عطّل نسخة الإضافة السابقة إن وُجدت. اضغط **نسخ المسار وفتح إضافات Edge**، وفعّل **Developer mode**، ثم **Load unpacked** واختر مجلد الإضافة الذي نسخ التطبيق مساره. افتح الإضافة وأدخل رمز الربط المكوّن من 8 أرقام.
4. بعد ظهور الاتصال داخل الإضافة، ارجع إلى التطبيق واضغط **إتمام الإعداد بعد التحقق** عندما تُصبح كل المتطلبات جاهزة. يستمر التحقق من الاتصال في الخلفية. ارجع إلى المثبّت واضغط Next ثم Finish؛ يظل الوصول إلى هذه الخطوة محجوبًا حتى نجاح التحقق.
5. افتح ReelShort من زر التطبيق، وسجّل الدخول بالطريقة العادية في الموقع. حدّث الصفحة بعد تحميل الإضافة، وافتح قائمة الحلقات ثم ابدأ الفحص من الإضافة.
6. صدّر **CSV لجميع الحلقات**، واختره صراحةً من التطبيق. حدد حلقات أو اترك التحديد فارغًا لتنزيل جميع الروابط الصريحة. يمكن تغيير مجلد الحفظ وإيقاف التنزيل واستئنافه باختيار الفهرس نفسه مرة أخرى.

**التفعيل يتم داخل Edge:** الزر يفتح صفحة الإضافات وينسخ المسار؛ لا يغيّر سياسات المتصفح ولا يدّعي إمكانية التفعيل الصامت. المرجع: [Microsoft — تحميل الإضافة محليًا](https://learn.microsoft.com/microsoft-edge/extensions-chromium/getting-started/extension-sideloading).

المثبّت الصامت يرفض التشغيل قبل نسخ الملفات لأن التفعيل التفاعلي لا يمكن إثباته فيه. إذا أغلقت نافذة الإعداد قبل التحقق، يبقى المثبّت على صفحة Verify Microsoft Edge. اضغط Retry للمحاولة مجددًا، أو Cancel للخروج دون نجاح. قد تبقى الملفات المثبتة؛ أعد تشغيل المثبّت أو أزل التطبيق من إعدادات Windows. لا تُحذف التنزيلات أو بيانات المستخدم عند الإزالة.

## البيانات والحدود

- تحفظ بيانات الاتصال والتقارير في `%LOCALAPPDATA%\ReelShortDownloaderTop`، والتنزيلات في مجلد Downloads الفعلي للمستخدم، مع دعم المجلدات المعاد توجيهها.
- لا يقرأ التطبيق كوكيز Edge أو كلمات المرور. قناة `127.0.0.1:18765` مخصصة للربط والتحقق فقط، ولا تقبل أوامر تنزيل.
- `MediaURL` في فهرس الحلقات هو مصدر التنزيل؛ **HLSCandidateURL يبقى مرشحًا غير مؤكّد ولا يُنزّل تلقائيًا**. قد تنتهي صلاحية روابط الفيديو؛ أعد الفحص والتصدير عند الحاجة.
- يُسجل النجاح فقط بعد خروج أداة التنزيل بنجاح وفحص وجود مسار فيديو بواسطة FFprobe. لا يعني ذلك مراجعة المحتوى كاملًا أو إثبات تطابق الحلقة؛ يلزم فحص بشري للتطابق على الموقع الحقيقي.
- لا يفتح المشروع حلقات مقفلة، ولا يستخرج مفاتيح DRM، ولا يتجاوز حقوق الوصول. استخدمه للمحتوى الذي يحق لك حفظه.
- لا تتوفر شهادة توقيع للتطبيق أو المثبّت في هذه المرحلة؛ الحزم التطويرية غير موقّعة.

## البناء من المصدر

على Windows x64 مع Python 3.12 وNode 22 و[Inno Setup 6](https://jrsoftware.org/isinfo.php):

```powershell
python -m pip install -r build-requirements.txt
python -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/extension.test.cjs
.\scripts\Download-Dependencies.ps1
python scripts/package.py
& 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' installer\ReelShortDownloaderTop.iss
```

لا تنفّذ السكربتات القديمة كجزء من تثبيت التطبيق. أدوات الحزمة تُحمّل في بيئة البناء من روابط محددة وتُراجع ببصمات SHA256 في `vendor-lock.json`. أي عدم تطابق يوقف البناء دون تحميل بديل غير موثق.

اختبارات المتصفح تستخدم صفحة محلية مماثلة لبنية الموقع وفيديو اختبار مصطنع. تشغيلها:

```sh
npm install --no-save --package-lock=false playwright@1.56.1
npx playwright install chromium
node tests/browser.cjs
```

عند دفع وسم `v*`، تُبنى الحزم تلقائيًا وتُنشأ **مسودة إصدار تجريبي** فقط، بعد نجاح الاختبارات. لا تُنشر نسخة إنتاجية تلقائيًا. راجع [اختبار القبول على Windows](docs/ACCEPTANCE.md) قبل النشر.
